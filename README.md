An **Industry 4.0 IIoT telemetry and predictive maintenance platform** monitoring CNC machine vibration (ISO 10816 standards), Overall Equipment Effectiveness (OEE), and real-time harmonic waveforms.

---

## 🌟 Features
- 🏭 **OEE Metric Analysis:** Tracks machine Availability, Performance, and Quality yield.
- 📡 **Real-Time Spindle Vibration Telemetry:** Fast Fourier Transform (FFT) harmonic peak monitoring.
- 🚨 **Predictive Maintenance Alert Engine:** Auto-flags bearing degradation before mechanical failure occurs.

---

## 🚀 Quick Start
```bash
git clone https://github.com/rushikeshgarad2024-dev/smart-manufacturing-iiot-dashboard.git
```
